   - Regulation 2021 (CBCS), Admission Batch 2023–2027, Affiliated to Anna University.

   - Overall Attendance rate (94.5%).

2. **Semester-wise Results (Sem 1 to Sem 3)**:
   - **Semester 1 (Nov/Dec 2023)**: 23 Credits, SGPA: 8.52 (Professional English, Matrices & Calculus, Physics, Chemistry, Python, Labs).

## 🚀 Getting Started

1. Navigate to the project directory:
   ```bash
   cd "unit - 5 project - 1/unit-5-pro-1"
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
