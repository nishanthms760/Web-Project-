# Unit 4 Project 2 - Developer Portfolio

**Nishanth M S — Computer Science Engineering Student | Aspiring Software Engineer**

A modern, responsive, and visually developer-focused portfolio built with React and Vanilla CSS. Designed with rich glassmorphism aesthetics, dynamic dark/light theme switching, interactive skills filtering, project deep-dives, printable CV generator, and direct contact dispatch.

## 🛠️ Tech Stack

- **Framework**: React 19
- **Bundler**: Vite 8
- **Styling**: Vanilla CSS (Custom Design System, Tokens, Glassmorphism, Responsive Grid)
- **Typography**: Plus Jakarta Sans, Syne, Fira Code

## 💻 Getting Started Locally

1. Navigate to the project directory:
   ```bash
   cd "unit - 4 project - 2/unit-4-pro-2"
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
