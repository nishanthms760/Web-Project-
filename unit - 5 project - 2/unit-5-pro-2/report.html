STUDENT DAILY DIARY & TASK PLANNER USING REACT

Aim

To develop a comprehensive Student Daily Diary and Task Planner website using React that enables students to organize academic tasks, schedule routines across 5 structured time-slots (Morning, College/School, Afternoon, Evening, and Night), write persistent diary reflections, and track weekly productivity metrics through a multi-page interface powered by React Router.

Procedure

Step 1: Creating the React Application

A React application is initialized using Vite for high-performance development and bundling. The project structure is cleanly organized into reusable components, dedicated pages, global context providers, API communication services, and modular CSS style sheets to make the system scalable, testable, and maintainable.

The application contains separate sections for:

  • Dashboard & Overview Analytics
  • Daily Diary & Time-Slot Management
  • All Tasks & Multi-Criteria Filter
  • Weekly Planning Schedule
  • Academic Calendar
  • Completed Tasks Archive
  • Student Profile & Study Stats

Step 2: Creating the Application Layout

The main App.jsx file is configured to establish the global layout structure, housing navigation components and route definitions.

The application layout contains:

  • Collapsible Responsive Sidebar Navigation
  • Top Navigation Bar with Quick Task Creation
  • Global Add/Edit Task Modal Dialog
  • Context State Wrappers (Theme, Auth, and Task Providers)
  • Dynamic Route Switcher for Protected Content

The navigation system allows the student to transition smoothly between daily scheduling, long-term calendar views, and performance tracking.

Step 3: Creating the Student Profile

A dedicated Profile page is implemented to maintain the student's personal identity, academic milestones, and productivity streaks.

A reusable profile card and account management form display the student's vital information and study statistics.

The profile includes:

  • Student Name & Academic Email
  • Degree and Department (B.E. CSE)
  • Profile Avatar
  • Active 5-Day Study Streak Badge
  • Cumulative Task Count & Completed Total
  • Weekly Productivity Index (Completion Rate %)
  • Account Information & Password Update Form

The profile section establishes user identity and motivates consistent daily study habits through progress streaks.

Step 4: Implementing React Router

HashRouter, Routes, Route, Navigate, and NavLink from react-router-dom are configured for client-side routing and protected navigation.

The application contains the following primary routes:

  • / – Dashboard Overview & Task Analytics
  • /diary – Daily Diary Journal with 5 Time Slots
  • /weekly – 7-Day Planning Schedule Grid
  • /tasks – All Tasks with Search and Filter Chips
  • /completed – Completed Tasks Archive
  • /calendar – Academic Calendar View
  • /profile – Student Profile & Streak Metrics
  • /settings – User Preferences & Theme Controls
  • /login, /register, /forgot-password – Authentication Views

This modular routing architecture renders each functional study module as an independent view while preserving persistent navigation.

Step 5: Creating the Daily Diary System

The DailyDiary and DiarySection components create an authentic journal interface organized by date and daily segments.

The diary system includes:

  • Interactive Date Navigation (Previous Day, Live Date Header, Next Day)
  • Morning Routine Slot (06:00 AM – 11:59 AM)
  • School / College Lectures & Practical Labs Slot
  • Afternoon Study & Assignments Slot (12:00 PM – 04:59 PM)
  • Evening Projects & Homework Slot (05:00 PM – 08:59 PM)
  • Night Revision & Reflection Slot (09:00 PM – 11:59 PM)
  • Permanent Database Journal Notes with Character Counter and Auto-Persistence

A reusable TaskCard component displays individual tasks with time stamps, subjects, priority chips, and status toggles inside their respective time buckets.

Step 6: Creating Task Management and Filtering

The AllTasks page provides end-to-end task lifecycle management (Create, Read, Update, Delete) with rapid filtering capabilities.

The task management system includes:

  • Real-time search across task titles, subject courses, and descriptions
  • Filter chips: All, Pending, In Progress, Completed, High Priority, Today, This Week, Overdue
  • Priority tagging with color hierarchy (High: Red, Medium: Yellow, Low: Blue)
  • Inline status toggling to instantly mark tasks complete
  • Modal dialog for detailed task creation with dates, timings, subjects, and types

Step 7: Storing and Synchronizing Data

A centralized TaskContext provider and API service layer (taskService.js, diaryService.js) manage global state synchronization.

The data layer handles:

  • Full CRUD synchronization with Express REST backend
  • Automatic fallback to browser LocalStorage for offline continuity
  • Real-time notification toast system for operation feedback
  • Dynamic calculation of weekly completion percentages and overdue tallies

Step 8: Creating Weekly and Calendar Views

Separate perspective views help students organize workload across broader time horizons:

  • WeeklyView: Renders a 7-day horizontal grid dividing tasks by weekday.
  • CalendarPage: Displays a monthly calendar grid highlighting active deadlines and exam milestones.

Step 9: Creating Dashboard Analytics

The Dashboard provides an immediate executive summary of academic commitments:

  • Metric summary cards: Total Tasks, Due Today, In Progress, and Completed
  • Visual completion progress bar and weekly rate indicator
  • Quick-action shortcuts to add tasks or jump directly to today's diary
