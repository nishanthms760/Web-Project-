# Unit 4 Project 1 - React Application

This project is set up with Vite and React.

## Getting Started

1. Navigate to the project directory:
   ```bash
   cd "unit - 4 project - 1/unit-4-pro-1"
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```
